# 唐詩星圖

**在线版：<https://ztm-njau.github.io/tang-sky/>** · 无需安装，打开即入夜

把《全唐诗》的每一首诗，投影成夜空中的一颗星。

**57,215 首 · 3,637 位诗人 · 40 个意象维度 · 实测 61 FPS** —— 每首诗按其意象构成一个高维向量，
经 landmark-MDS 降维落在二维星图上：意象相近的诗自然靠近，聚成三十六个星团；
诗篇本身的气象（意象浓度 × 篇幅）决定它的星等。检索、漫游、点亮、结座。

## 三个技术决策（每个都是"没选更省事的做法"）

1. **为什么是 landmark-MDS，不是 t-SNE/UMAP** —— 全量两两相似度在 57k 规模下是 10⁹ 量级，
   t-SNE/UMAP 的实现要么吃内存要么引依赖；landmark-MDS 取 1,400 个地标 + Gower 插值，
   纯 Float64Array 手写，O(N·L)，40 秒跑完，且保持"距离有意义"的全局几何——
   星图要能漫游，局部成团但全局乱序的嵌入不行。
2. **为什么向量中心化后要带符号平方根** —— 第一版把负值截零，结果大多数诗向量互相正交
   （余弦距离恒等于 1），低维投影全部塌向 hub，星图变成一条细丝。
   保留"低于平均"的负信息后，相似度才真正由意象轮廓决定。
3. **为什么零构建、零运行时依赖** —— 作品集项目的第一秒是"打开"，不是"npm install"。
   全部产物是静态文件，GitHub Pages 直接托管；星表是手排的二进制格式（每星 16 字节），
   比等价 JSON 小 6 倍，57k 星一次 draw call。

## 数据从哪来

[ chinese-poetry ](https://github.com/chinese-poetry/chinese-poetry) 开放数据集《全唐诗》58 卷，
经 OpenCC 统一为简体，残句剔除后 57,215 首。诗文按 12 个分片懒加载。

## 星图是怎么算出来的（tools/build.js）

1. **意象向量化** —— 40 个意象维度（月、风、雪、剑、雁、酒、宫阙、闺怨……），
   每维度统计标题命中（加权）与正文命中次数（`1 + log₂ n`），
   乘 IDF 压制「千/百/无/空」这类泛字，再减语料均值中心化，
   带符号平方根压缩后 L2 归一化。带符号是关键：截零会让多数诗向量互相正交，
   余弦几何塌成一堆 hub。
2. **landmark-MDS** —— 全量两两相似度是 10⁹ 量级，改取 1,400 个地标，
   地标间余弦距离双中心化后幂迭代取前两特征向量，
   其余点按 Gower 插值投影（`x = −0.5 Σ (d²−d̄)·v/√λ`）。复杂度 O(N·L)。
3. **银河带整形** —— 主轴 PCA 旋转至水平，主/次轴分位数缩放
   （3,600 × 1,500 世界单位），密度脊即成一条有厚度的银河。
4. **k-means 星团** —— k-means++ 初始化，36 团；命名按「区分度」认领：
   星团内意象均值 ÷ 全语料均值，显著偏高（>1.15）的意象对应的诗句名归该团
   （如「玉门关外」「陌头杨柳」「曲径通幽」）。
5. **kNN 邻星表** —— 网格哈希加速，每星 6 邻，供「邻星跳转」。

全流程 ~40 秒，随机种子固定（20261104），构建可复现。

## 前端（public/）

- **js/gl.js** —— WebGL2 渲染器。程序化星点（无贴图）：核心 + 光晕双高斯剖面，
  加色混合，逐星异相闪烁；星云层为全屏 fbm 噪声银河辉光；9,000 颗尘埃远星
  提供视差纵深。三 pass 绘制，57k+ 星 60fps。
- **js/app.js** —— 相机（惯性拖拽 / 滚轮缩放 / 双指捏合 / 双击飞行）、
  网格拾取、诗文卷轴（竖排）、检索（题名 > 作者 > 首句加权）、意象过滤、
  星团标注、星印（localStorage）、连星成座与 URL 分享。

## 三个钩子

- **今夜主星** —— 以日期为种子，每晚从名篇中选定一颗主星，点击即飞。
- **星印** —— 读过的诗可以盖一枚星印，星星常亮；「星印」模式聚焦所有读过的星。
- **连星成座** —— 任意挑至多 7 颗星连成你自己的星座，命名后生成分享链接。
